# Ink & Iron — web build
Static build for GitHub Pages. A rules-only WWII grand-strategy game: no AI, no accounts, no network calls; saves stay in your browser.


## v5
- 960 provinces (about 10 per country, more for large ones) on a much finer map grid, drawn with cached 256px tiles so it stays light on phones; deep zoom.
- Division-level war: armies sit in regions; tap one to move or attack a neighbouring region. Battles run over several two-day phases using infantry/armour/artillery, air superiority, terrain, rivers, forts, entrenchment, supply, morale, organisation and commanders. Includes breakthroughs, retreats, encirclement pockets and naval invasions, with a battle report after each fight.
- Allies tab: call to arms (allies can say no and give a reason; three refusals end an alliance), defensive pacts, expeditionary forces, lend-lease, intelligence sharing, joint war goals, coordinated attacks, joint or separate peace, faction kick/leave, region gifts, embargo demands, protection, secret protocols, ultimatums.
